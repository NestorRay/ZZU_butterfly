# 蝴蝶扑翼机控制系统

## 1. 项目简介

基于 ESP8266/ESP32 一体化控制板的轻量化扑翼飞行器。本项目通过解析 ELRS 遥控信号，利用正弦波算法驱动双舵机，模拟昆虫的自然扑翼动作。其核心优势在于极致的重量控制与高自由度的参数化配置。

## 2. 遥控控制映射

系统通过 `CRSF` 协议获取遥控数据，并将其映射为逻辑控制量。默认的摇杆分布如下：

| 变量名称 | 物理摇杆/通道 | 作用说明 |
| --- | --- | --- |
| `freq` | 左摇杆垂直方向 (LY) | **油门/频率**：决定扑翼的扇动快慢 |
| `yaw` | 左摇杆水平方向 (LX) | **偏航**：通过改变两侧翅膀行程差实现转向 |
| `pitch` | 右摇杆垂直方向 (RY) | **俯仰**：整体改变翅膀中立点，实现抬头/低头 |
| `offset` | 右摇杆水平方向 (RX) | **微调**：手动修正机械偏差，调整平衡 |
| `swb` | 三段开关 B | **幅值切换**：切换 ±35°/±45°/±55° 三档幅度 |
|`swc`|三段开关 C |**并翅**：向上向下并翅或保持水平|

## 3. 核心数学原理

### A. 信号处理：一阶低通滤波

为滤除遥控信号的电磁噪声和手指抖动，系统对输入量采用了指数加权移动平均算法：


$$y(n) = \alpha \cdot x(n) + (1 - \alpha) \cdot y(n-1)$$

* **因子 $\alpha$**：由 `YDIFLY_FACTOR_FILTER` 定义。值越小，信号越平滑但响应越慢。

### B. 运动生成：正弦波映射

翅膀的往复运动遵循标准的正弦曲线，以保证舵机在换向时的平滑性：


$$Angle_{set} = \frac{max - min}{2} \cdot \sin\left( \frac{time \cdot 2\pi}{T} \right) + \frac{max + min}{2}$$

### C. 节奏控制：非线性时间畸变

系统通过 `YDIFLY_SPEED_DIFF` 参数打破了正弦波的对称性：

* **当 $time\_now$ 处于周期中段 ($0.25T \sim 0.75T$)**：执行 `time_now -= speed_diff`。这会减慢时间流速，使**下扑动作更深沉、有力**。
* **其他区间**：执行 `time_now += speed_diff`。这会加速时间流速，使**上回弹动作更迅速**。

## 4. 关键参数调试指南 (`ydifly.h`)

| 宏定义 | 默认值 | 调试建议 |
| --- | --- | --- |
| `YDIFLY_CONTROL_CYCLE` | 25ms | 舵机更新周期。减小可提高平滑度，但需注意芯片算力负荷。 |
| `YDIFLY_SPEED_DIFF` | 0 | 扑翼节奏差。设为正值可增加下扑力度，增加升力。 |
| `YDIFLY_FACTOR_PITCH` | 0.025f | 俯仰灵敏度。如果蝴蝶抬头太猛，请调小此值。 |
| `YDIFLY_SERVO_X_DIR` | 0 / 1 | 舵机方向。如果翅膀扇动方向反了，直接修改此位。 |

---

## 5. 开发说明

* **时间管理**：系统采用“时间补全”机制（`last_time_ms_control += YDIFLY_CONTROL_CYCLE`），有效消除了任务调度的累积误差，确保飞行节拍绝对稳定。
* **硬件驱动**：放弃了标准的 `Servo.write()`，采用 `startWaveform8266` 直接控制 PWM 占空比，以实现微秒级的精准控制并降低系统开销。
